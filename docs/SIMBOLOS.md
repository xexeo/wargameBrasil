# Legenda completa dos símbolos — Monte Castelo Vibed

Revisão0.9.3. A mesma legenda ilustrada fica aberta em **Regras & símbolos**, em português e inglês americano. Cores são configuráveis: a forma, a letra e o contexto determinam o significado.

## S no círculo amarelo/âmbar

**S = suprimida.** Pode aparecer depois de um acerto de fogo indireto ou de uma retirada para reorganização. Enquanto a peça estiver suprimida, não faz fogo de oportunidade nem contra-ataca. O S não causa dano adicional, não aumenta defesa e, sozinho, não retira o ataque normal.

O marcador desaparece no início do próximo turno do lado da unidade. Reorganização ou reação já gasta pode continuar comprometendo a própria ação nesse turno; o duplo toque/clique mostra esses estados por extenso. Isso é diferente de perder PV. O círculo S também não é a bolinha central da artilharia, nem uma das pequenas bolinhas de coesão.

## Peças, letras e números

| Desenho / marca | Significado |
| --- | --- |
| Quadrado azul / carvão, FEB / DE | Lado brasileiro / alemão. As cores podem ser alteradas; o texto identifica o lado. |
| Retângulo com X dentro | Infantaria; apoio orgânico continua pertencendo à arma de infantaria. |
| Ponto grande no centro do retângulo | Artilharia. Não mede dano nem coesão. |
| Elipse no retângulo | Blindados, quando presentes. Não há peça blindada no cenário atual. |
| I acima da companhia | Escalão companhia. |
| II na identificação do batalhão/grupo | Escalão batalhão ou grupo de artilharia; desenho original da opção batalhão preservado. Na convenção militar, a marca de escalão é colocada acima do símbolo. |
| X acima de um símbolo militar | Convencionalmente brigada; não confundir com o X da infantaria dentro do retângulo. Não é uma formação presente no jogo. |
| A/I, B/II, C/III | Companhia A do batalhão I, B do II, C do III. Letras A/B/C são etiquetas de cenário, não numeração histórica local comprovada. |
| AP | Apoio agregado, não uma companhia extra de fuzileiros confirmada. |
| DEST | Destacamento alemão de cenário; escalão e efetivo locais não confirmados. Não afirmar que toda peça é uma companhia histórica identificada. |
| T1 / T2 / T3 | Perfil reduzido / operacional / especializado em fogos. Não é patente, efetivo ou bônus oculto. |
| · entre rótulos | Separador de texto, não ponto de coesão. |
| A / D / M | Ataque nominal / defesa nominal / movimento restante. A e D são parâmetros de jogo por escala, não número de homens. |
| 3/3, 2/3, 1/3 | Coesão atual / inicial. Toda peça começa com 3 PV relativos à sua escala. |
| Pequenas bolinhas douradas | Uma por PV de coesão restante. Não representam soldados individuais. |
| PV / HP | Pontos de coesão/resistência, em português/inglês. |
| PM / MP | Pontos de movimento, em português/inglês. |
| Selo vermelho −1 ou −2 acima da peça | Dano **acumulado** desde os3PV iniciais. Não é o ataque da peça. Pode marcar−2 numa companhia após dois acertos de 1 PV. |
| S no círculo âmbar | Supressão; explicado acima. |
| Traço diagonal sobre a peça | Ataque normal usado ou comprometido por reação/reorganização. Não indica destruição. Disparar normalmente não impede gastar PM restantes, se a peça puder agir. |
| Reorganizando / Reação gasta | Estados escritos na inspeção; não possuem um ícone próprio adicional no mapa. Podem impedir ações mesmo depois de desaparecer o S. |
| Contorno reforçado da peça | Seleção/foco. As ações destacadas pertencem à peça selecionada. |

Na companhia revisada, agir com uma unidade **não bloqueia as companhias irmãs**. A regra antiga de esmaecer/bloquear companhias por comando de batalhão foi retirada. As reações comprometem somente a própria peça. A opção batalhão conserva suas regras.

## Mapa e ações

| Desenho / marca | Significado |
| --- | --- |
| Contorno contínuo de hexágono | Destino alcançável com os PM atuais. Toque para mover. |
| Borda tracejada de destino | Risco de fogo defensivo no percurso calculado. Não é obstáculo nem dano garantido. |
| Barra e contorno de ataque sobre inimigo | Alvo legal da seleção. Toque na peça inimiga para atacar. |
| Estrela vermelha central e anel tracejado | Objetivo. Não é marcador de dano ou alvo de artilharia separado da peça. |
| +2/rod ou +1/rod | Pontos por fechamento de rodada com infantaria FEB de manobra ocupando o objetivo. Máximo4 por rodada; meta8 acumulada. |
| N1–N4, ~850 m e curvas | Faixa de altura, cota aproximada e curvas de nível interpoladas. Não são níveis de experiência de unidades. |
| Árvores agrupadas e manchas de bosque | Mata e base geográfica moderna; não levantamento da vegetação de 1945. |
| Abrigo, trincheiras e pequeno bloco | Posição preparada esquemática; não localização histórica individual comprovada. |
| Linha de via / tracejado fino | Estrada / trilha ou caminho da base moderna. Só a classificação do hexágono no motor define o custo de movimento. |
| Pequenos polígonos e arcos de relevo | Edificações atuais e símbolo esquemático de morro. Não são unidades, objetivos ou bônus extras independentes. |
| N ↑ e barra500m | Norte e escala geográfica aproximada. |
| FEB/DE ou marcas de ocupação nos objetivos | Lado que ocupa a posição; apoio e artilharia não asseguram objetivos. |

## Disparos e interface

| Desenho / marca | Significado |
| --- | --- |
| Balas em rajada | Animação de infantaria. |
| Granada com aletas, arco alto | Morteiro do apoio agregado. |
| Projétil alongado com cintas, arco mais baixo | Obus de artilharia. Obus é o projétil; obuseiro é a arma. Não identifica um calibre específico. |
| Clarão, rastro, anel e explosão | Disparo/impacto de um evento já resolvido. Não são elementos clicáveis ou acertos adicionais. |
| Ataque / Fogo defensivo / Contra-ataque | Tipo do evento. A seta textual liga quem atira ao alvo, não é ordem de movimento. |
| −1 PV / −2 PV junto do impacto | Perda **daquele disparo**, diferente do selo acumulado da peça. Na companhia revisada, cada disparo causa no máximo1PV; batalhões continuam podendo causar2. |
| Sem perda de coesão | O disparo não retirou PV; não significa ausência de um evento de combate. |
| ⚑ junto de Missão | Destaque do objetivo da operação; não é um novo objetivo no mapa. |
| ＋ em Nova partida | Inicia outro jogo; não é zoom. |
| ☰ | Menu responsivo. |
| + / −, percentual e controle deslizante | Zoom, não modificadores de ataque/defesa. |
| → em Encerrar turno | Passa o comando ao outro lado. |
| ☀ / ⛅ / ☁ | Nebulosidade regional estimada, não penalidade automática de combate. |
| Caixa de seleção marcada | Preferência ativada, como som/animação; não estado militar. |
