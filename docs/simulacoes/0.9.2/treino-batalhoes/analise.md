# Treino battalion

Uma passagem:2.400 jogos para cada modelo fixo (FEB/Alemanha),400 por política adversária, e2.000 para a Veterana online. Hiperparâmetros fixos alpha0,18/gamma0,9/epsilon0,20; inferência fixa epsilon0. As tabelas e os dados individuais contêm sementes. Não transferir pesos entre escalas. Resultados durante exploração não são avaliação independente.

O estado da companhia usa prefixo próprio e coesão relativa normalizada pela força inicial; batalhão mantém as chaves legadas. Modelos fixos são congelados recursivamente; a Veterana tem sua própria cópia no navegador. Recompile e avalie após este treino.
